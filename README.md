# Proje Bilgileri:  Akçaabat Kargo

### Grup Üyeleri (Bireysel Proje)
* *Burak Can Küçükbekir*

### Proje Adı
Akçaabat Kargo - Akıllı Takip Sistemi

### Projenin Amacı
Bu proje, Django tabanlı geliştirilmiş, AI destekli ve modern arayüze sahip bir kargo takip otomasyonudur. Sistemin temel amacı; kargo operasyonlarını dijitalleştirerek verimliliği artırmaktır. Proje; trafik ve hava durumuna göre teslimat süresi tahmini yapan *AI Akıllı Tahmin, benzersiz takip numarası üretimi, harita destekli **Canlı Takip* ve kullanıcı dostu Karanlık Mod gibi gelişmiş özellikler sunmaktadır.

### Görev Dağılımı (Bireysel)
* *Burak Can Küçükbekir:* Projenin tüm backend mimarisi (kargo_sitesi, takip), veritabanı tasarımı, AI tahmin algoritmalarının entegrasyonu ve frontend arayüz geliştirmelerinden tek başına sorumludur.

---
### 🚀 Teknik Özellikler ve Kurulum
* *AI Akıllı Tahmin:* Teslimat süresi analizi.
* *Canlı Takip:* Harita üzerinden kurye konumu ve teslimat kanıtı sistemi.
* *Admin Paneli:* Kargo ve kurye yönetimi için gelişmiş yönetim paneli.

*Kurulum:*
1. pip install -r requirements.txt
2. python manage.py migrate
3. python manage.py runserver
